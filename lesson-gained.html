Guide to Pseudo effects on button:
If the text in the button has a preset color, specifying color in the button declaration will not work. Two things to do:
  • Remove the preset color
  • If 1 is not possible, declare using the button selector then hover then text tag. for example: 
                    HTML:
                <button>
                    <p>Add to Cart</p>
                </button>

                CSS:
                button:hover p{
                    color: 
                }

Notable disadvantage to using in-code svg:
Using hover on the outline and fill is lackluster, the fill is much 'detectable' than the outline.

Apparently running "html:" will perform the same effect as "!" on an html file.
